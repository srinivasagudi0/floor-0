# floor-0

A tiny creepy elevator game for Hack Club Shrink.

You start on floor 12 and your goal is simple:
get to floor 0

But the elevator is kinda broken.

# Sometimes

- It skips floors
- Talks to you!!!
- It wants to destroy your screen(our safety protections are against it.)
- whole system gets corrupted (Please quickly press the buttons 3 times to get it back to working.)


It gets darker and quiter as you go down and uses Web audio for the elevator sounds.

## How to play

- ↑ goes up
- ↓ goes down
- Reach floor 0
- If the system breaks, keep pressing the buttons
